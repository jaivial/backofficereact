# E2E Edge — Pantalla 10: Stock

Ruta: `/app/stock`.

## Interacciones reales de usuario
- Ver resumen de stock (existencias, cobertura).
- Gestionar almacenes.
- Crear nuevo ítem.
- Cambiar entre secciones (tabs: Existencias / Movimientos / Mermas...).

## Edge cases
1. Carga sin error; resumen con valores.
2. Tabs de sección cambian el contenido.
3. Apertura de "Nuevo ítem" (formulario) y cierre sin persistir.
